## Worked example scripts

In the [`examples/`](https://github.com/daibeal/esnfed/tree/main/examples) folder:

- **[`tutorial_finance.ipynb`](https://github.com/daibeal/esnfed/blob/main/examples/tutorial_finance.ipynb)** —
  an end-to-end federated counterparty-risk walkthrough (also rendered as the
  [Tutorial](tutorial.ipynb) page).
- **`plotly_gallery.py`** — regenerates the interactive plots above.
- **`flower_federated_ridge.py`** — the [Flower](guide/interop.md) integration.
- **`make_animations.py`** — regenerates the GIFs above.

## Reproduce the research experiments

```bash
pip install -e ".[experiments,viz,reservoirpy,flower]"
python experiments/run_all.py        # synthetic-benchmark figures and tables
python experiments/exp6_finance.py   # federated counterparty-risk study
python experiments/exp7_fedres_prompt.py   # FedResPrompt cost benchmark
```
