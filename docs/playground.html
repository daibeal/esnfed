esnfed playground

Everything here runs live in your browser — a tiny Echo State Network (reservoir + ridge readout) implemented in plain JavaScript. Drag the sliders, press play, re-roll the reservoirs, and watch it move.  ← back to the docs

1 · Reservoir activations how it reacts to input

Each dot is a reservoir neuron and the lines are its connections; colour is the activation as the input drives the network, and node size grows with degree (so scale-free hubs stand out). Switch the structure — ring, small-world, scale-free or random — to see how connectivity changes the dynamics. The right panel runs the echo state test: two copies start from different states and get the same input — if their distance shrinks to zero, the network has forgotten where it started (the echo state property holds). A spectral radius below 1 guarantees this; raising it lengthens the memory (the start is forgotten more slowly). Pick an input and press play.

2 · Central vs Federated vs Local vs Ensemble the strategies

A memory+nonlinearity task is split across clients. Watch the predictions get traced out. Federated ridge pools the clients' summary statistics and lands exactly on centralized. Local-only models degrade as each client is starved of data. The ensemble averages heterogeneous reservoirs and sits in between. Bars show test NRMSE (lower is better).

3 · Short-term memory how far back it remembers

Can the reservoir reconstruct the input it saw k steps ago? Each bar is the recovery (R², 0–1) at delay k. Memory fades with delay, and reaches further as the spectral radius approaches 1.
